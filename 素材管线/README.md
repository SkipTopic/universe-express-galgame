# 素材管线：从手写照片到可进引擎的美术与文本

这里放的是**小说数字化阶段的脚本**——把一本童年手写的日记（212 页照片）洗成小说正文、再洗成 galgame 剧本和美术素材，用的那套工具。

> **日记原文不在这个仓库里。**
> 212 页转写的内容包含大量与本游戏无关的私人记录（梦、随笔、早期构思、日常），属于个人隐私，已从仓库和历史中彻底移除。这里只保留处理脚本和流程说明——工具是中性的，内容不是。

---

## 目录

| 路径 | 内容 |
|---|---|
| `脚本/` | 12 个 Python 脚本，按流程编号看 |
| `美术脚本/` | 5 个美术处理脚本（抠图 / 对齐 / 早年代码画图） |
| `转写规范.md` | OCR 转写时遵守的记号约定（划掉、看不清、插图、页眉怎么标） |

## 脚本：每一环在干什么

### 一、先保证照片是正的

| 脚本 | 作用 |
|---|---|
| `检查方向.py` | 自动检测照片有没有拍歪——印刷横线在正立页面上应当水平周期分布，靠这个判断 |
| `缩略图检查.py` | 把 33 张疑似横置的页拼成缩略图，人工目检，顺带导出 3 张存疑裁剪 |
| `调试图.py` | 给需要手工校正的页生成调试图：整页缩小 + 红色裁剪框 + 10% 网格 |

手机拍 212 页，总有几张横着、几张斜着。这三步是人工介入最多的地方。

### 二、转写与清洗

| 脚本 | 作用 |
|---|---|
| `颜色分段.py` | **核心工具**。手写稿里红蓝墨水和铅笔混着写，这个脚本把墨色标记还原成 `(文字, 颜色)` 段，后面所有导出都调它 |
| `提取小说.py` | 从 212 页转写里抽出小说正文，输出 `宇宙快递员·正文.docx`（143250→145902，连续 61 页） |
| `补丁_抬头.py` | 补丁：过滤信纸的印刷抬头行（就是第 1 章那句 `Subject.　Date.`） |

清洗规则三条：**划掉的内容不显示、红蓝墨水还原成字色、保留手写换行**。

### 三、润色

| 脚本 | 作用 |
|---|---|
| `润色准备.py` | 把 61 页正文按章节分组，清洗后导出，插图位置留 `[插图：文件名]` 占位 |
| `润色组装.py` | 12 章润色完，重新组装成一本 docx，每章另起一页 |

润色出来的 12 章就是 [`../剧本修复/原剧本/`](../剧本修复/原剧本/) 里的那 12 个文件，再往下改写成成品脚本。

### 四、另外两条导出支线

| 脚本 | 作用 |
|---|---|
| `生成word.py` | 整本日记的 OCR 复刻 Word（纯文字版 + 带图版，212 页） |
| `生成网页.py` | 「我的日记」H5 网页，按分类浏览 |
| `生成手册.py` | 辨认手册生成器：把存疑条目按页配上原图，打印出来对着原稿核 |

这三条支线是日记项目的副产品，不是游戏必需，但脚本留着了——同一套清洗逻辑复用。

### 五、美术

| 脚本 | 作用 |
|---|---|
| `美术脚本/重抠立绘.py` | 立绘抠图 v2：flood fill 从画布边缘连通去白底 |
| `美术脚本/对齐立绘.py` | 立绘画布归一化：中心 x=666、脚底 y=1970，按 base 内容高缩放 |
| `美术脚本/生成美术.py` | **第一版美术**：用 PIL 纯代码画背景/立绘/CG |
| `美术脚本/美术引擎.py` | 上一行的绘图库（渐变、星层、噪点、剪影、光束、人物） |
| `美术脚本/扫描BGM.py` | 全盘扫本机音乐 → 复制进 `assets/audio/bgm/scan/` |

`生成美术.py` 值得单独说一句：**在接入豆包之前，美术是代码画的。** 17 张背景、7 张立绘、4 张 CG，全是 PIL 一层层叠渐变和剪影画出来的。效果当然不行（就是色块加轮廓），但把引擎先跑通了，后面换真图时才不用改一行代码。这套东西后来被全部替换，脚本留作记录。

## 没有上传的东西

这里只留了脚本和流程，原始素材一律没有进仓库。原因分两类：**隐私**和**体积**。

### 因为隐私移除的（已从全部历史中删除）

| 内容 | 说明 |
|---|---|
| 212 篇日记转写 | 含梦、随笔、早期构思、日常记录，与本游戏无关 |
| 194 张插图裁剪的位置索引 | 描述的是整本日记里的涂鸦，不只游戏用到的那些 |
| 图片清单 / 页序 / 批次表 | 212 张照片的元数据，随原文一并移除 |

### 因为体积没上传的

| 内容 | 体积 | 说明 |
|---|---|---|
| `美术/帧验证存档/` | 1.6G | 705 张逐帧验收截图。验证过程的证据，不是生产物料 |
| `美术/旧立绘备份_v1~v4/` | 84M | 历次立绘备份，已被最新版替代 |
| `美术/重生成_*/` | 74M | 豆包重生成时的原始输出 jpg，成品已进 `assets/sprites/` |
| `裁剪图片/` | 77M | 194 张插图裁剪，游戏实际用到的 6 张已在 `assets/cg/` |
| `完整日记word输出/` | 55M | 生成的 docx 成品，不是过程 |
| `待辨认/` | 32M | 存疑清单和辨认手册，与游戏无关 |
| `__pycache__/`、`日志/`、`残留*.txt` | — | 纯垃圾 |

**本地的原始文件一个都没删**，只是没有进仓库。
