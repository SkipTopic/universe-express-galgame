# AI 漫剧预告片 · 第一阶段文本开发包

> 目标产物：一支 **2 分钟（120 秒）、动漫画风、用于引流/预告的 AI 漫剧短片**
> 本文档只解决一件事：**在生成任何一张画面之前，你必须先把哪些"文字"写清楚。**
> 原则：**先有文字 Bible（设定圣经），再出画面。** 文字越具体，AI 出图越稳定、人物越不会"变脸"、镜头越不会"跳戏"。

---

## 一、整支漫剧的生产阶段图（先看清全局）

| 阶段 | 名称 | 这一阶段做什么 | 产出物 |
|---|---|---|---|
| **阶段 0** | 选题与定位 | 从游戏/小说里挑一个最适合做预告的故事，定类型、观众、钩子 | 选题结论 + 一句话故事 |
| **阶段 1（当前）** | **文本开发** | 写齐"项目定位 / 剧情 / 人物 / 环境 / 状态 / 感觉 / 分镜 / 生成规范"全套文字 | 本文档 + 角色卡 + 场景卡 + 分镜脚本 |
| 阶段 2 | 视觉开发 | 定画风、出角色三视图/表情集、场景概念图、全片色板（Color Script） | 美术风格指南、角色设定图、场景概念图 |
| 阶段 3 | 故事板 Animatic | 把分镜做成带时间、带配乐节拍的"动态草稿/翻页动画"，先验证节奏 | 动态故事板视频（粗剪） |
| 阶段 4 | 静帧生产 | 按镜头逐张生成关键帧画面，锁定人物/场景一致性 | 每个镜头的成图 |
| 阶段 5 | 动态化 | 图生视频 / 运镜 / 人物表演 / 粒子特效，让静帧"动起来" | 每个镜头的视频片段 |
| 阶段 6 | 声音制作 | 配音/旁白、BGM、音效、环境音，卡点 | 人声轨、音乐轨、音效轨 |
| 阶段 7 | 剪辑合成 | 拼接、转场、字幕、调色、片名 Logo、Slogan、片尾钩子 | 成片（横屏/竖屏版本） |
| 阶段 8 | 复盘与物料 | 封面、标题、简介、话题标签、多平台尺寸切片 | 发布物料包 |

> 关键认知：**预告片 ≠ 把剧情压缩讲一遍。** 预告片是"贩卖情绪和悬念"，让观众产生"想玩/想看"的冲动。所以阶段 1 的核心不是复述完整剧情，而是**挑名场面、定情绪曲线、埋钩子**。

## 二、2 分钟预告片"到底从哪开始"

### 2.1 起点不是画图，而是这三件事（按顺序）

1. **一句话故事（Logline）**：用一句话说清"谁，在什么处境，要面对什么，赌注是什么"。
2. **一条情绪曲线**：120 秒内，观众的情绪要被你怎么"带"（平静 → 温暖 → 不安 → 危机 → 爆发 → 留白）。
3. **一份名场面清单**：从原故事里挑 8～15 个"最有画面感、最能代表这个故事"的瞬间，预告片只用这些。

这三样定了，后面的人物卡、场景卡、分镜才有主心骨。**这就是第一阶段的第一锹土。**

### 2.2 推荐的 120 秒结构（可直接套用）

| 时间 | 段落 | 作用 | 典型内容 | 情绪 |
|---|---|---|---|---|
| 0–10s | **冷开场钩子** | 3 秒内抓住人 | 一个反常/震撼/极美的画面 + 一句悬念台词或字幕 | 悬念 / 震撼 |
| 10–35s | **世界与人物建立** | 让人认识主角、爱上世界 | 主角日常、世界观空镜、伙伴/羁绊、温柔瞬间 | 温暖 / 好奇 |
| 35–75s | **冲突升级** | 制造压力与裂痕 | 异常出现、危机逼近、回忆闪回、关系受考验 | 不安 / 紧张 |
| 75–105s | **高潮爆发** | 全片情绪顶点 | 对决 / 崩溃 / 抉择 / 生离死别 / 觉醒 | 燃 / 虐 / 燃爆 |
| 105–115s | **情绪落点** | 给观众一口气、点题 | 一个安静镜头 + 一句点题台词 | 释然 / 回味 / 泪点 |
| 115–120s | **片名与钩子** | 告诉观众这是什么、接下来干嘛 | 游戏/作品 Logo + Slogan + 上线/关注信息 | 记忆点 |

> 镜头数量参考：2 分钟预告片一般 **24～40 个镜头**，平均每镜 3～5 秒；高潮段可快切（1～2 秒/镜），情绪落点用长镜（6～8 秒）。

## 三、第一阶段必须写齐的文本（8 大模块）

你点名的"人物、环境、剧情、状态、感觉"都在里面，并补齐了让 AI 真正能开工所必需的另外几块。**每一块都给了可直接复制填写的模板（见第四节）。**

### 模块 A · 项目定位（Project Brief）
- **A1 一句话故事 Logline**
- **A2 预告片目的**：给游戏引流 / 涨粉 / 剧情安利 / 角色安利 / 战斗燃向 / 治愈情绪向
- **A3 目标观众画像**：年龄段、性别倾向、喜欢哪类作品、在哪个平台刷到
- **A4 核心钩子（Hook）**：观众看完最该记住的那一个点（一个设定反转 / 一对关系 / 一句台词）
- **A5 情绪关键词**：3～5 个，贯穿全片（如：孤独、温柔、宿命、燃、释然）
- **A6 动漫画风定位**：明确风格谱系与参考（如：日系热血少年番 / 新海诚式光影 / 吉卜力手绘治愈 / 赛博朋克 / 国漫厚涂 / 暗黑奇幻），并写清"要什么质感、不要什么质感"
- **A7 技术规格**：时长 120s；画幅（横屏 16:9 还是竖屏 9:16，或两版都要）；帧率；发布平台
- **A8 声音形式**：纯音乐 / 旁白独白 / 角色台词 / 字幕卡，分别占多少

### 模块 B · 剧情文本（Story）
- **B1 世界观设定**：时代、星球/城市、社会规则、科技或魔法体系、这个世界独有的"设定规则"
- **B2 原作完整梗概**：把游戏主线用 300～800 字讲清（给自己看，保证不写错设定）
- **B3 预告片叙事线**：预告片单独的讲述顺序（可以打乱原作时间线，先给结果再倒叙）
- **B4 名场面清单**：8～15 个候选高光瞬间，每个注明"画面是什么 / 为什么选它 / 情绪是什么"
- **B5 三幕/起承转合分配**：把名场面填进第二节的 120 秒结构
- **B6 悬念与反转**：哪些信息提前露、哪些藏到正片/游戏里（预告片要"留白"）
- **B7 关键台词/旁白文案**：冷开场字幕、点题句、结尾 Slogan、Call To Action
- **B8 情绪曲线表**：逐段标注情绪强度（1–10）和情绪类型

### 模块 C · 人物文本（Character Bible，每个角色一张卡）
- **C1 基础档案**：姓名、年龄、性别、身份、在故事里的功能（主角/对手/羁绊/引导者/吉祥物）
- **C2 外貌设定**：身高体型、发型发色、眼睛（颜色/眼神/有无义眼或特殊特征）、肤色、脸型、年龄感
- **C3 标志性特征（一致性锚点）**：**每次 AI 生成都必须保留的 3～5 个不可变特征**（如：右眼下的痣、红色围巾、机械义眼、银白短发）——这是防止"变脸"的关键
- **C4 服装设定**：常服、关键场合服装、主配色、材质（布/皮革/金属）、配饰、武器或随身道具
- **C5 表情集（状态）**：常态、微笑、大笑、愤怒、悲伤、惊恐、决绝、疲惫等，每种一句话描述
- **C6 性格与气质关键词**：如"外冷内热、沉默、护短"
- **C7 前史与动机**：身世、创伤、想要什么、害怕什么（决定他/她为什么有这种眼神）
- **C8 人物关系**：和谁是亲人/战友/对手/暗恋，彼此的情感张力
- **C9 角色弧光**：在这 2 分钟里，他/她从什么状态变到什么状态
- **C10 标志动作/姿态**：习惯性小动作、战斗起手式、站姿（生成画面时的"动作库"）
- **C11 声音设定**：声线（年龄感/音色/语速/口癖），为后续配音/AI 语音准备
- **C12 出场镜头清单**：这个角色在预告片哪几个镜头出现、分别什么状态

### 模块 D · 环境 / 场景文本（World & Scene Bible，每个场景一张卡）
- **D1 场景名称与功能**：这个地点在故事里是哪、承担什么情绪（家=温暖，废墟=创伤）
- **D2 时间与天气**：白天/黄昏/夜；晴/阴/雨/雪/雾/沙尘
- **D3 光线与色调**：光源方向、冷暖、硬光还是柔光、主色调（这决定画面气质）
- **D4 空间布局**：前景/中景/远景分别有什么，镜头通常朝哪个方向看
- **D5 关键道具与符号**：这个场景里反复出现、有象征意义的物件（钢琴、旧照片、信号灯……）
- **D6 氛围描述**：一句话的"感觉"，以及五感（声音、温度、气味联想）
- **D7 世界观视觉符号**：贯穿全片的意象（某种花、某种光、某个徽记、某种颜色）
- **D8 动态元素**：风、飘动的布、飘落的花瓣/灰/雪/火星、流动的云、人群、电流
- **D9 出场镜头**：该场景在哪些镜头出现

### 模块 E · 状态文本（State：表演与镜头内状态）
> "状态"是把文字变成画面时最容易漏、却最决定质感的一层。每个镜头都要写清四种状态：
- **E1 人物状态**：身体姿势、手部动作、面部表情、眼神看向哪、情绪强度（1–10）
- **E2 关系调度**：人物之间的距离、谁在前谁在后、谁面向谁、谁背对镜头
- **E3 环境状态**：此刻的风/光/粒子/天气/时间，以及它们如何变化
- **E4 镜头状态**：景别（远景/全景/中景/近景/特写）、机位（俯/仰/平视）、运镜（推/拉/摇/移/环绕/手持晃动/固定）、焦距与景深（虚化背景）、镜头时长与节奏

### 模块 F · 感觉 / 情绪文本（Mood & Feeling）
- **F1 全片基调**：一句话定调（如"一场温柔外壳下的告别"）
- **F2 分段情绪目标**：每一段"想让观众心里产生什么感受"
- **F3 五感氛围词库**：为每个场景写视觉、听觉、温度、气味联想词（喂给 AI 做氛围）
- **F4 画面氛围关键词库**：孤独、窒息、壮阔、治愈、神圣、破败、温暖、清冷……（中英对照，供 Prompt 用）
- **F5 参考板 Mood Board 清单**：需要去收集哪些参考（画风参考、光影参考、配色参考、镜头参考、角色气质参考）
- **F6 音乐情绪与节拍点**：哪里进鼓点、哪里突然静音、哪里高潮爆发（先标情绪点位，阶段 6 再配乐）

### 模块 G · 分镜脚本（Storyboard，阶段 1 的收尾产物，承上启下）
- 把前面所有模块"编译"成一张镜头表，每个镜头一行（模板见第四节 G）。
- 分镜表通过后，才进入阶段 2 的视觉开发。

### 模块 H · AI 生成规范（Production Bible / "一致性宪法"）
- **H1 统一画风前缀（Style Prompt）**：一段固定文字，**每张图都带**，锁定画风（线条、上色、渲染、镜头质感）
- **H2 统一画质词**：高细节、电影感打光、景深、构图等
- **H3 负面词 Negative**：不要 3D 感、不要真人写实、不要多余手指/崩坏、不要画风跳变、不要水印文字
- **H4 角色一致性规则**：固定锚点词、固定种子/参考图（角色三视图作为角色参考图反复调用）
- **H5 场景一致性规则**：同一场景用同一张场景概念图做参考，固定色调与布局
- **H6 命名与归档规范**：镜头编号、图片/视频/音频文件命名规则、版本号
- **H7 镜头→资产对照表**：每个镜头需要哪张角色图、哪张场景图、什么 Prompt、输出到哪个文件夹
